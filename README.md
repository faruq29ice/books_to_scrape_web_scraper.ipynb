#  Books to Scrape Web Scraper

A Python web scraping project that extracts book information from the Books to Scrape sandbox website using Requests, BeautifulSoup, and Pandas.

---

##  Project Overview

This project demonstrates how to:

- Send HTTP requests
- Parse HTML pages
- Extract structured data
- Visit individual product pages
- Clean scraped data
- Export data to CSV

---

##  Dataset

The final dataset contains:

- Title
- Price
- Rating
- Stock Status
- Quantity Available
- Product Type
- UPC
- Price (Excluding Tax)
- Price (Including Tax)
- Tax
- Number of Reviews

---

##  Technologies Used

- Python
- Requests
- BeautifulSoup4
- Pandas
